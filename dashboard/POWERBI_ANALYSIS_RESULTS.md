## Dashboard design decisions

- Ranked role, skill, employer and city comparisons use horizontal bars.
- Work Mode and Location Scope use donut charts because they are small part-to-whole compositions.
- Salary Availability uses a donut chart to emphasize the limited salary-disclosure share.
- Empty threshold-based salary charts were replaced with salary sample-size charts, making sample support visible instead of showing blank visuals.
- Skill Category Mix was replaced by Top Skill Co-occurrence because pair demand is a stronger interview finding.
- Each page uses a six-KPI multi-value card strip that responds to the report slicers.
