# Power BI Dashboard Guide

## Data Analyst Job Market Intelligence: Skill, Experience & Salary Analytics — India

This folder contains the Power BI reporting layer for the Data Analyst Job Market Intelligence project. The dashboard presents the validated analytical dataset through five report pages covering hiring demand, skills, experience, employers, locations, salary availability, and recent market trends.

## Power BI Project

Open the dashboard from:

```text
dashboard/DataAnalystJobMarketIntelligence.pbip
```

The `.pbip` file should remain beside its associated Power BI project folders so Power BI Desktop can load the report and semantic model correctly.

## Data Connection

The dashboard connects to PostgreSQL using:

```text
Server:   localhost
Database: job_market
Schema:   job_market
```

Primary reporting objects:

```text
job_market.vw_jobs_enriched
job_market.vw_job_skills
```

The semantic model is based on the validated analytical outputs generated by the Python pipeline and loaded into PostgreSQL.

## Refreshing the Dashboard

1. Open `DataAnalystJobMarketIntelligence.pbip` in Power BI Desktop.
2. Confirm PostgreSQL is running locally.
3. Confirm the connection points to:
   - server: `localhost`
   - database: `job_market`
   - schema: `job_market`
4. Click **Home → Refresh**.
5. If Power BI asks for native-query approval, review and approve the read-only `SELECT` / `WITH ... SELECT` queries used by the project.
6. Wait for all tables to finish loading.
7. Clear slicers and verify the core dashboard counts.

## Reporting Notes

- Salary values are not imputed.
- Source-predicted salary is excluded from salary analysis.
- Skill counts use explicit extracted skill mentions.
- Missing experience remains `Not Specified`.
- Recent-vs-prior skill comparisons are descriptive, not forecasts.
- Salary comparisons are associations, not causal claims.
- Sparse salary coverage is always shown with sample-size context.
